# 原価ノート

飲食店（うどん店・バーなど）のメニュー原価計算アプリです。
材料の仕入れ値とレシピから、メニューごとの **原価・原価率・粗利・目標の売価** を計算します。
HTML・CSS・JavaScript だけで動き、ビルドやサーバーは不要です。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 平均原価率、販売数で加重した月の原価率・粗利、目標超えメニュー、3か月以上見直していない材料 |
| メニュー（一覧／試算） | レシピ（材料・仕込み × 使う量）＋その他（容器・箸など）から原価を計算。試算では月の想定販売数から売上・原価・粗利、仕入れ値が○%上がったときの影響と必要な値上げ率 |
| 読取 | レシート・納品書・請求書・値札・チラシの写真や PDF を Claude が読み取り、お店・日付・商品・内容量・価格を記録。保存前に確認・修正でき、材料の原価にも反映できる |
| 材料（材料／仕込み） | 仕入価格（税抜・税込8%・税込10%）・内容量・単位・歩留まりから1単位あたりの単価。お店別の価格の記録・手入力、仕入れ値の履歴。仕込み（だし・タレなど）のできあがり量あたりの単価 |
| 買い物（今日の買い物） | 買う材料と量を選ぶと、その日に有効なチラシの特売といつもの価格から、どのお店で買うと一番安いかを計算。回るお店の数（1店増やす手間）も考えておすすめを出す。お店ごとのチラシURLから、すぐチラシを開ける |
| 買い物（比較・提案） | 材料ごとに一番安いお店、お店のランキング（価格指数）、使い分けたときの月の節約額、お店別の買い物リスト、AIへの買い方の相談 |
| 設定 | 店舗の追加・切り替え、目標原価率、売価の端数、CSV出力、印刷、バックアップ／復元、ライト・ダーク表示 |

## 計算式

- 材料の1単位あたり ＝ 税抜の仕入価格 ÷（内容量 × 歩留まり）
  - 例: 冷凍うどん玉 1,100円 / 25玉 → 44円/玉
- 仕込みの1単位あたり ＝ 材料費の合計 ÷ できあがり量
  - 例: かけだし 材料費 793.3円 / 10,000ml → 0.079円/ml
- メニューの原価 ＝ Σ（1単位あたり × 使う量）＋ その他（円）
  - 例: かけうどん ＝ 44.0 + 27.8（だし350ml）+ 3.5（ねぎ5g）+ 3.0（箸）＝ 78.3円
- 原価率 ＝ 原価 ÷ 税抜売価（税込売価 ÷ 1.1、持ち帰りは ÷ 1.08）
  - 例: 78.3 ÷（450 ÷ 1.1 = 409.1）＝ 19.1%
- 目標の売価（税込）＝ 原価 ÷ 目標原価率 × (1 + 税率)、設定した単位（1・10・50・100円）で切り上げ
- 値上がり時に必要な値上げ率 ＝ 増える原価 ÷ 今の売上（税抜）
- お店比較の単価 ＝ 税抜価格 ÷ 内容量（材料の単位に換算。kg→g、L→ml）。歩留まりはどのお店でも同じなので含めない
  - 例: 牛バラ 200g 358円（税込8%）→ 358 ÷ 1.08 ÷ 200 ＝ 1.66円/g
- 価格指数 ＝ そのお店の単価 ÷ 最安値の単価 の平均 × 100（100 に近いほど安い。2店以上で記録がある材料だけで比較）
- 月の節約額 ＝（今の原価の単価 − 最安値の単価）× 月の使用量
- 今日の買い物：お店ごとの価格 ＝ その日に有効なチラシの特売と、いつもの価格（チラシ以外の最新の記録）の安いほう（税込）
  - 支払額の目安 ＝ 1単位あたりの税込価格 × 買う量（パックの大きさの違いは考えない）
  - お店の組み合わせをすべて試し、「支払額 ＋ お店を1つ増やす手間（初期値 300円）×（回るお店の数 − 1）」が一番小さいものをおすすめにする
  - チラシの価格は特売期間中だけ使い、比較・提案（いつもの価格の比較）には入れない
  - 月の使用量 ＝ Σ（メニューの月の想定販売数 × 1人前の使う量）÷ 歩留まり（仕込みは材料まで分解）

表示は原価が小数第1位、原価率が小数第1位、粗利・売上が1円単位（四捨五入）です。

## 使い方

1. ファイル一式をそのままWebサーバーに置く（Netlify・GitHub Pages など）か、PCで `python -m http.server` を実行して `http://localhost:8000/` を開く
2. 最初の画面で「うどん店の見本」「バーの見本」を選ぶか、店舗名を入れて空から始める
3. 材料 → 仕込み → メニューの順に登録する
4. iPhone は Safari の共有 →「ホーム画面に追加」でアプリのように使えます（HTTPS ならオフラインでも開けます）

## チラシについて

お店のホームページのチラシは自動では取りに行きません。チラシは画像や PDF で載っていることが多く、チラシ掲載サイトには自動での取得を禁止しているところもあるためです。
「お店とチラシURL」にチラシのページを登録しておき、「チラシを見る」から開いて、スクリーンショットか PDF を保存して「チラシを読み取る」で読み取ってください。

## 読み取りの設定（Netlify で公開する場合）

読み取りと「AIに相談」は Claude を使います。

- **claude.ai のページで開いた場合**：閲覧している人の Claude アカウントで動くので、設定はいりません（最初の1回だけ利用の確認が出ます）。
  - 画面によっては画像を Claude に直接送れません。そのときは端末の中で文字を読み取ってから（PDF は文字情報、写真は tesseract.js の日本語文字認識）、文字だけを Claude に送って整理します。レシートの文字を貼り付けて読み取ることもできます。
- **Netlify などで公開した場合**：同梱のサーバー関数 `netlify/functions/read.mjs`（`/api/read`）が Claude API を呼び出します。
  1. [Claude Console](https://platform.claude.com/) で API キーを発行する（API の利用料が別にかかります）
  2. Netlify の Site configuration → Environment variables に `ANTHROPIC_API_KEY` を登録する
  3. 他人に使われないよう、`APP_PASSCODE`（合言葉）も登録し、アプリの 設定 →「読み取り（Claude）の接続」に同じ合言葉を入れる
  4. 再デプロイする

API キーはサーバー側だけに置き、ブラウザには渡しません。読み取りに使う画像は長い辺 1,600px に縮めて送り、端末には保存しません。

## データの保存について

データはその端末のブラウザ（localStorage）だけに保存されます。別の端末とは共有されません。
設定 →「バックアップを書き出す」で JSON ファイルを保存し、機種変更や別の端末では「バックアップから復元」で戻してください。
ブラウザのデータ削除やプライベートブラウズでは消えることがあるため、定期的なバックアップをおすすめします。
