# 原価ノート

飲食店（うどん店・バーなど）のメニュー原価計算アプリです。
材料の仕入れ値とレシピから、メニューごとの **原価・原価率・粗利・目標の売価** を計算します。
HTML・CSS・JavaScript だけで動き、ビルドやサーバーは不要です。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 平均原価率、販売数で加重した月の原価率・粗利、目標超えメニュー、3か月以上見直していない材料 |
| メニュー | レシピ（材料・仕込み × 使う量）＋その他（容器・箸など）から原価を計算。分類順／原価率順／粗利順 |
| 材料 | 仕入価格（税抜・税込8%・税込10%）・内容量・単位・歩留まりから1単位あたりの単価。仕入れ値の履歴 |
| 仕込み | だし・タレ・天ぷらなど、まとめて作るもの。できあがり量あたりの単価をメニューで使える |
| 試算 | 月の想定販売数から売上・原価・粗利。仕入れ値が○%上がったときの影響と必要な値上げ率 |
| 設定 | 店舗の追加・切り替え、目標原価率、売価の端数、CSV出力、印刷、バックアップ／復元、ライト・ダーク表示 |

## 計算式

- 材料の1単位あたり ＝ 税抜の仕入価格 ÷（内容量 × 歩留まり）
  - 例: 冷凍うどん玉 1,100円 / 25玉 → 44円/玉
- 仕込みの1単位あたり ＝ 材料費の合計 ÷ できあがり量
  - 例: かけだし 材料費 793.3円 / 10,000ml → 0.079円/ml
- メニューの原価 ＝ Σ（1単位あたり × 使う量）＋ その他（円）
  - 例: かけうどん ＝ 44.0 + 27.8（だし350ml）+ 3.5（ねぎ5g）+ 3.0（箸）＝ 78.3円
- 原価率 ＝ 原価 ÷ 税抜売価（税込売価 ÷ 1.1、持ち帰りは ÷ 1.08）
  - 例: 78.3 ÷（450 ÷ 1.1 = 409.1）＝ 19.1%
- 目標の売価（税込）＝ 原価 ÷ 目標原価率 × (1 + 税率)、設定した単位（1・10・50・100円）で切り上げ
- 値上がり時に必要な値上げ率 ＝ 増える原価 ÷ 今の売上（税抜）

表示は原価が小数第1位、原価率が小数第1位、粗利・売上が1円単位（四捨五入）です。

## 使い方

1. ファイル一式をそのままWebサーバーに置く（Netlify・GitHub Pages など）か、PCで `python -m http.server` を実行して `http://localhost:8000/` を開く
2. 最初の画面で「うどん店の見本」「バーの見本」を選ぶか、店舗名を入れて空から始める
3. 材料 → 仕込み → メニューの順に登録する
4. iPhone は Safari の共有 →「ホーム画面に追加」でアプリのように使えます（HTTPS ならオフラインでも開けます）

## データの保存について

データはその端末のブラウザ（localStorage）だけに保存されます。別の端末とは共有されません。
設定 →「バックアップを書き出す」で JSON ファイルを保存し、機種変更や別の端末では「バックアップから復元」で戻してください。
ブラウザのデータ削除やプライベートブラウズでは消えることがあるため、定期的なバックアップをおすすめします。
